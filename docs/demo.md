# A focused winning demo

Chert's [HackUTA page](https://www.trychert.com/uta) gives creative video use
double weight. A walking guide is already one of its template ideas. Differentiate
Aurora with an everyday transaction that combines visual help and communication.

## Three-minute story

1. Call Aurora through the assigned Chert line, with the rear camera on.
2. Present a bill. Ask for its denomination. Show a different denomination so
   judges can see that recognition follows the changing camera.
3. Obscure it. Aurora should ask for a clearer view instead of guessing.
4. In a controlled indoor scene, show a conspicuous obstacle and ask for a scene
   description. A high-priority detection can interrupt ordinary speech; never
   demonstrate by approaching traffic or a real weapon.
5. Ask for translation into another language. Speak a short exchange with an
   agreed participant; show the captions and let ElevenLabs speak the translation.
6. Request a recap. It should recall this call's observations and exchange.
7. Mute the camera. Aurora must say it cannot currently see, not describe an old
   frame. End the call and immediately make a second call to prove clean reset.

Use an actual ASL signer if demonstrating signing. Label the optional static
letter service as fingerspelling assistance; do not call it full ASL translation.
Only include sentence-level ASL after validating a separate temporal model.

## Recommended next additions

- **Change-checking workflow:** caller confirms price and amount tendered; Aurora
  reads returned bills and compares the observed total with expected change.
  Require currency consistency and separate read uncertainty from arithmetic.
- **User-controlled verbosity:** quiet mode for hazards, detail on request.
  Pause/resume alerts is already available.
- **Human help on uncertainty:** offer a trusted person's help after repeated
  unclear views. Adding a friend needs explicit consent and enabled group-call
  support; no automatic call or message is implemented.
- **Measured reliability:** record aggregate timing and success rates on staged
  cases, not private videos. Present actual results and failures to judges.

## Required rehearsal

Verify speech in both directions, the caller's changing video, our changing
status card on the phone, and earpiece routing. Exercise mute/unmute, camera
replacement, freeze, unclear cash, mixed currencies, translation cancellation,
alert pause/resume, provider failure, hangup, and a fresh second call. Confirm
the first audible greeting occurs within Chert's 10-second readiness window.

Check balances in each provider account and current Chert trial limits. Chert's
CLI doctor is a setup check; it is not proof of working two-way media.
